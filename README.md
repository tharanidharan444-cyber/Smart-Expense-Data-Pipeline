Smart-Expense-Data-Pipeline
A beginner-friendly end-to-end Data Engineering project that processes expense data using Python, Pandas, PostgreSQL, and SQL. The pipeline cleans raw CSV data, loads it into PostgreSQL, and generates useful spending insights through SQL analytics.

 Architecture

CSV → Python → Data Cleaning → PostgreSQL → SQL Analytics

Technologies

- Python
- Pandas
- PostgreSQL
- SQL
- Git
- GitHub

Features

- CSV data ingestion
- Data cleaning
- Duplicate removal
- Missing value handling
- PostgreSQL data loading
- Expense analytics
- Category-wise spending analysis
- Payment method analysis
- Daily spending analysis
